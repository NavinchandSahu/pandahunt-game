## Panda Hunt Game 🐼🎯  
A fun reaction-based desktop game built using Python and Tkinter where players hunt a moving panda within a time limit to score points.

## Overview
Panda Hunt is a timer-based clicking game where a panda image continuously moves around the screen.  
Players click on the panda to score points before time runs out.  
The game becomes a test of speed, focus, and accuracy—all wrapped in a playful UI with animations.

---

## Features
- Moving panda animation with boundary detection
- Countdown-based gameplay
- Score updates in real time
- Random repositioning when clicked
- Start, Restart, and Quit buttons
- Clean & simple GUI using Tkinter
- Perfect for practicing event handling & game logic in Python

---

## Tech Stack
- **Language:** Python  
- **GUI Library:** Tkinter  
- **Modules Used:** `random`, `time`

---

## How to Play
1. Enter the duration (in seconds)
2. Click **Start**
3. Try to tap the panda as many times as possible while it moves
4. Score increases with every click
5. When time ends, **Final Score** is displayed
6. Click **Restart** to play again
